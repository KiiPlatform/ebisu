ebisu API reference

The API of ebisu, the embedded IoT suite for Kii, for each major version.

ebisu 3.x

The current release. Its API differs from 1.x's, so devices still on 1.x should use that version's reference below.

tio kii khc jkii

ebisu 1.x

The last 1.x release line, 1.3.

tio kii khc jkii

Development

The master branch, which may change before it is released.

tio kii khc jkii

Components

tio
Onboards the device, uploads its state, and runs the commands it receives. Most devices need only this one.
kii
The Kii Cloud API tio is built on, including its key-value and file storage.
khc
The HTTP client tio and kii use.
jkii
The JSON parser tio and kii use.
