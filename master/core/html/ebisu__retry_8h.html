◆ ebisu_retry_spread()

uint32_t ebisu_retry_spread ( uint32_t wait,
uint32_t seed )

A device's share of a wait: from half of it, rounded up, to all of it.

The share changes as the wait doubles, so a device doesn't wait the same part of each; once the wait is at the longest, a device waits the same share of it each time. Devices still differ from one another, which is what spreads them out.

Parameters
[in]waitThe wait, in the caller's unit.
[in]seedThe device's, from ebisu_retry_seed().
Returns
From wait - wait / 2 to wait: 0 for 0, 1 for 1.

The wait after the n-th failure in a row.

first, doubled n - 1 times and max at most, then spread as ebisu_retry_spread() spreads it. A max below first cuts the first wait short too. Nothing overflows, for any n, first and max.

Parameters
[in]firstThe first wait, in the caller's unit.
[in]maxThe longest wait, in the same unit.
[in]nThe failures in a row, from 1. 0 is taken as 1.
[in]seedThe device's, from ebisu_retry_seed().
Returns
The wait, in the unit of first and max.
