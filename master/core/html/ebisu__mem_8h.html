void ebisu_secure_zero ( void * p,
size_t n )

Sets n bytes at p to 0, which the compiler can't leave out.

A memset() just before memory is freed, or goes out of scope, is a store nothing reads afterwards, which an optimizing compiler may remove, leaving what was there. ebisu clears with this what held a password, a token or MQTT credentials, once it is done with them. An application can do the same with its own, such as a kii_t, which holds the thing's tokens, before its memory is used for something else.

Parameters
[out]pThe memory. May be NULL when n is 0.
[in]nHow many bytes.
