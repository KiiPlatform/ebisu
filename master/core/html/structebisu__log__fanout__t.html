Detailed Description

A logger that gives each message to several others.

Each of them is given every message, in the order of the array, and decides what to do with it, as platform's loggers do with a level of their own. So one logger set on a port can send its diagnostics to, say, stderr and syslog at once. It may be called from more than one task at once if each of them may. It depends on nothing of the system's, so it serves an embedded device too.

Initialize with ebisu_log_fanout_init().
