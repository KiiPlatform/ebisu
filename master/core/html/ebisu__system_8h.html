typedef struct ebisu_lock_ops_t ebisu_lock_ops_t

What a lock does.

The lock need not be recursive.

While it is held, other tasks may be kept waiting for the length of an HTTP request, and the operations ebisu calls in between include those of the sockets. A platform on which no other task using the same session can run while the lock is held – including inside those operations – may implement both as no-ops.
