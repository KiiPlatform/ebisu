enum ebisu_sock_code_t

Indicates socket callback result.

Enumerator
EBISU_SOCK_OK 

Return this code when operation succeed.

EBISU_SOCK_FAIL 

Return this code when operation failed.

EBISU_SOCK_AGAIN 

Return this code when operation is in progress.

This code is used when the underlying socket is non-blocking mode. The operation is called again with the same arguments until it returns EBISU_SOCK_OK or EBISU_SOCK_FAIL.

◆ ebisu_sock_error_t

enum ebisu_sock_error_t

Why a socket operation failed, as the socket can tell. See ebisu_socket_ops_t::last_error.

Enumerator
EBISU_SOCK_ERROR_NONE 

Nothing failed, or the socket can't tell why.

EBISU_SOCK_ERROR_DNS 

The host name didn't resolve. The detail is the resolver's error, such as getaddrinfo()'s.

EBISU_SOCK_ERROR_CONNECT 

None of the host's addresses took the connection. The detail is the system's error, as errno has it.

EBISU_SOCK_ERROR_TLS 

TLS failed, in the handshake or after it, for another reason than the server's certificate. The detail is the TLS library's error.

EBISU_SOCK_ERROR_VERIFY 

The server's certificate was refused. The detail is why, as the TLS library says it, such as OpenSSL's X509_V_ERR_* codes.

EBISU_SOCK_ERROR_TIMEOUT 

A timeout ran out: looking the host up, connecting, sending or receiving.

EBISU_SOCK_ERROR_CLOSED 

The peer closed or reset the connection.

EBISU_SOCK_ERROR_OTHER 

Another failure. The detail is the system's error, if there is one.
