◆ ebisu_strbuf_t

typedef struct ebisu_strbuf_t ebisu_strbuf_t

A string built in a fixed buffer.

The buffer always holds a terminated string: what the appends that fitted appended, whole. An append that doesn't fit, with its terminating NUL, appends nothing, and the builder fails: every later append does nothing, and ebisu_strbuf_ok() is false. So appending a whole message and checking once at the end is enough, and a failed message is never sent cut short.

Initialize with ebisu_strbuf_init(). The fields are for reading only.

Parses a decimal number into a scaled integer: with decimals 2, "12.5" is 1250, "-0.05" is -5 and "7" is 700.

A '+' or '-' if wanted, digits, and a '.' with digits after it if wanted. There must be a digit before the '.' and after it, and no more digits after it than decimals: one more would have to be rounded away, which is EBISU_PARSE_INVALID rather than a silent change of the value.

Parameters
[in]sThe bytes.
[in]lenHow many.
[in]decimalsDecimal places of the result, up to EBISU_FIXED_MAX_DECIMALS. More are EBISU_PARSE_RANGE.
[in]minThe smallest value taken, scaled.
[in]maxThe largest value taken, scaled.
[out]outThe value, scaled.
Returns
EBISU_PARSE_OK, or why not.

bool ebisu_span_next ( ebisu_span_t * rest,
char delim,
ebisu_span_t * field )

Takes the next field from a span, up to a delimiter or its end.

Each call takes one field and advances *rest past it and its delimiter. Once the field taken is the last, *rest is used up: its ptr is NULL, and the next call returns false. So "a,b" gives "a" and "b", "a," gives "a" and "", and "" gives one field, "". Check len before the first call for no fields from an empty span.

Parameters
[in,out]restWhat is left to split.
[in]delimThe delimiter.
[out]fieldThe field taken, without its delimiter.
Returns
true, or false if *rest was used up, leaving *field alone.

◆ ebisu_strbuf_appendf()

void ebisu_strbuf_appendf ( ebisu_strbuf_t * sb,
const char * fmt,
... )

Appends a format, as snprintf() would, but only of strings: s, %.*s and %%.

For a message made of strings, such as a request's path, without the C library's printf(), which on a small device can take more room than the code that calls it. s appends a string, NULL taken as "". %.*s appends as many bytes of one as its int argument says, or fewer, stopping at a NUL, as printf() does, and all of it for a negative int. %% appends a ''.

The format is appended whole, or not at all: if it doesn't fit, or has another conversion, which it can't write, the builder fails and holds what it held before.

Parameters
[in,out]sbThe builder.
[in]fmtThe format, followed by its arguments.

◆ ebisu_strbuf_commit()

void ebisu_strbuf_commit ( ebisu_strbuf_t * sb,
size_t n )

Appends what was written in the room ebisu_strbuf_room() gave.

n as large as the room or larger, which can't have fitted with a NUL after it, appends nothing and fails the builder, as an append that doesn't fit does: so a writer that ran out of room is committed with SIZE_MAX. Committing 0 bytes never fails it. Either way the buffer is terminated again, after what the appends that fitted appended, whatever the writer left in the room. Does nothing once the builder has failed.

Parameters
[in,out]sbThe builder.
[in]nHow many bytes were written, without a NUL after them.

The room after the string, for a function that writes into a buffer itself, such as an escaper or an encoder, to append there.

What it writes is appended by ebisu_strbuf_commit(). Until then the builder holds what it held, and the room can be asked for again.

Parameters
[in]sbThe builder.
[out]out_sizeSize of the room, in bytes, with that of the terminating NUL: what a function writing a terminated string is given.
Returns
Where the room starts, the string's NUL; or NULL, with a size of 0, once the builder has failed, or for a buffer of size 0.
