Converts a UTC date and time to seconds since the epoch.

As a TLS stack gives a certificate's validity dates, for ebisu_clock_check_validity() for instance.

Parameters
[in]year1 to 9999.
[in]month1 to 12.
[in]day1 to the length of the month.
[in]hour0 to 23.
[in]minute0 to 59.
[in]second0 to 59, or 60 at 23:59 for a leap second, which is the same second as 00:00:00 of the next day: seconds since the epoch count no leap seconds.
[out]out_secondsSeconds since 1970-01-01T00:00:00Z, negative before it. Written only when converted.
Returns
true if converted, false if a field is out of range.
