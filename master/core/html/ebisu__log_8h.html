typedef struct ebisu_log_fanout_t ebisu_log_fanout_t

A logger that gives each message to several others.

Each of them is given every message, in the order of the array, and decides what to do with it, as platform's loggers do with a level of their own. So one logger set on a port can send its diagnostics to, say, stderr and syslog at once. It may be called from more than one task at once if each of them may. It depends on nothing of the system's, so it serves an embedded device too.

Initialize with ebisu_log_fanout_init().

◆ ebisu_log_level_filter_t

typedef struct ebisu_log_level_filter_t ebisu_log_level_filter_t

A logger that gives another the messages of a level that can change while it logs.

A message less important than the level is dropped before the other logger is given it, so it isn't formatted at all. Its level can be set from any task while others log through it, as from a configuration a server sends: under the lock it is given, which each message takes for as long as it reads the level, and no longer. So a change is for the messages that read the level after it: one that read it before may still reach the other logger after the change returns. It may be called from more than one task at once if the other logger may.

Initialize with ebisu_log_level_filter_init().

◆ ebisu_log_slot_t

typedef struct ebisu_log_slot_t ebisu_log_slot_t

A place for a logger that can be filled, changed or emptied while other tasks log through it.

It gives each message to the logger it holds, and drops it while it holds none. It takes the lock it is given for each message, while it gives it on, and to change the logger, so that a change returns once no message is going to the logger it held, which may then be closed: a logger to a syslog server is changed for one to another server, or one with another host name, by initializing the new one first, putting it in the place, and closing the old one. It may be called from more than one task at once, which take their turns at the lock, if the logger it holds may.

The logger it holds mustn't log through it, as the lock is held while it logs.

Initialize with ebisu_log_slot_init().
