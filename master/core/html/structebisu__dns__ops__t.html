Detailed Description

What the system's name servers are, and how one is asked.

Ports implement these for their kind of system, as platform's POSIX and Win32 ports do with ebisu_posix_dns() and ebisu_win32_dns(), and an application for a system of its own. See ebisu_object.h for how self leads to its state, if it has any.

ebisu_dns_asked_t(* ebisu_dns_ops_t::ask) (ebisu_dns_t *self, const ebisu_dns_addr_t *server, const unsigned char *query, size_t length, uint32_t timeout_ms, ebisu_dns_is_answer_t is_answer, void *userdata, char *why, size_t why_size)

Sends a query to a server over UDP, and waits for its answer.

Each datagram that comes from the server before timeout_ms runs out is given to is_answer, and one it takes ends the wait. Other datagrams are skipped. It must not wait longer than timeout_ms, nor end sooner but with the answer or a failure.
