192/*
193 * The ebisu_parse_ functions read len bytes at s, which need no NUL after
194 * them, and never read beyond them. They are strict: all len bytes have to be
195 * the number, with no spaces and no prefix, and leading zeros are allowed, as
196 * fixed-width fields have them. They don't depend on the locale and don't set
197 * errno. The result is written to *out only when they return EBISU_PARSE_OK.
198 *
199 * When a span both has a character that isn't part of a number and would be
200 * out of range, the result is EBISU_PARSE_INVALID.
201 */
