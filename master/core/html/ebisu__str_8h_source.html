202/*
203 * The ebisu_parse_ functions read len bytes at s, which need no NUL after
204 * them, and never read beyond them. They are strict: all len bytes have to be
205 * the number, with no spaces and no prefix, and leading zeros are allowed, as
206 * fixed-width fields have them. They don't depend on the locale and don't set
207 * errno. The result is written to *out only when they return EBISU_PARSE_OK.
208 *
209 * When a span both has a character that isn't part of a number and would be
210 * out of range, the result is EBISU_PARSE_INVALID.
211 */
