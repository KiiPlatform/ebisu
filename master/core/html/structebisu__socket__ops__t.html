Detailed Description

What a socket does.

Applications implement these for the target environment, doing TLS inside them unless the connection is insecure. See ebisu_object.h for how self leads to the socket's state.

ebisu_sock_error_t(* ebisu_socket_ops_t::last_error) (ebisu_socket_t *self, long *out_detail)

Why the last operation that returned EBISU_SOCK_FAIL failed.

Optional. khc asks it right after such a failure of connect, send or recv, before closing the socket, and khc_get_sock_error() gives the answer. An application can ask its MQTT socket from the callback set by kii_set_cb_mqtt_event().

◆ recv_timed_out

bool(* ebisu_socket_ops_t::recv_timed_out) (ebisu_socket_t *self)

Whether the last receive failed because its timeout ran out.

Optional, and asked only by the MQTT task. Its recv returns EBISU_SOCK_FAIL both when its receive timeout runs out with nothing received, which is routine on an idle connection, and when the connection is lost. This tells the two apart. It is called right after such an EBISU_SOCK_FAIL, before any other operation on the socket. See kii_set_mqtt_socket() for what the task does with the answer, and without one.

Parameters
[in]selfThe socket.
Returns
true if the receive failed because its timeout ran out, false if it failed for any other reason.
