Detailed Description

JSON parsed field data.

Input of jkii_parse().

Array of jkii_field_t is passed to jkii_parse().

End point of the array is specified by jkii_field_t::name and jkii_field_t::path. If both of jkii_field_t::name and jkii_field_t::path are NULL, jkii_parse() consider that it is the end point of the passed array.

◆ path

const char* jkii_field_t::path

Parsing target path. Input of jkii_parse().

This can point any field or element of array. BNF like notation of path is following:

path ::= '/' identifier subpath
subpath ::= '/' identifier subpath | ''
identifier ::= field | index
index ::= '[' 0 ']' | '[' [1-9][0-9]+ ']'
field ::= [char | escaped]+
char ::= any ascii characters expect '/', '[', ']' and '\'
escaped = "\\/" | "\\[" | "\\]" | "\\"
jkii_field_t::path

Definition jkii.h:196

If you want to get first element of color array in following json example:

{
"light" : {
"color" : [ 0, 128, 255]
}
}
path ="/light/color/[0]";

In rare cases, like following:

{
"[]/\\" : "rare"
}

You can specify that key as following:

path ="/\\[\\]\\/\\";

◆ type

jkii_field_type_t jkii_field_t::type

Parsed target value type. Input and Output of jkii_parse(). Inputted value is expected value type and outputted value is actual value type.

If type is set as jkii_field_type_t#JKII_FIELD_TYPE_ANY, then jkii_parse() ignore type checking.

If actual type is not matched expected type:

  • jkii_parse() set actual type.
  • if expected type is not jkii_field_type_t#JKII_FIELD_TYPE_ANY, then jkii_field_t::result becomes jkii_parse_err_t#JKII_FIELD_ERR_TYPE_MISMATCH.
  • if expected type is jkii_field_type_t#JKII_FIELD_TYPE_ANY, then jkii_field_t::result become jkii_parse_err_t#JKII_FIELD_ERR_OK.

The actual type of an integer follows its value: jkii_field_type_t#JKII_FIELD_TYPE_INTEGER if it fits in an int32_t, jkii_field_type_t#JKII_FIELD_TYPE_LONG if it fits only in an int64_t. One that fits in neither is jkii_field_type_t#JKII_FIELD_TYPE_LONG with jkii_field_t::result jkii_field_err_t#JKII_FIELD_ERR_NUM_OVERFLOW or jkii_field_err_t#JKII_FIELD_ERR_NUM_UNDERFLOW. Expected as jkii_field_type_t#JKII_FIELD_TYPE_INTEGER or jkii_field_type_t#JKII_FIELD_TYPE_LONG, any integer matches, and one past the range of the expected type is reported as overflow or underflow.
