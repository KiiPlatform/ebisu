Detailed Description

A parsed JSON primitive: its value together with the type read.

Filled in by jkii_parse_primitive(). Read the member of value that type selects; the others are not meaningful.

jkii_field_type_t jkii_primitive_t::type

Type of the primitive that was parsed, selecting a member of value.

JKII_FIELD_TYPE_NULL indicates the JSON literal null, in which case no member of value is set.

An integer is JKII_FIELD_TYPE_INTEGER if it fits in an int32_t and JKII_FIELD_TYPE_LONG if it fits only in an int64_t, whatever the widths of int and long. One that fits in neither is reported as JKII_PRIMITIVE_ERR_OVERFLOW or JKII_PRIMITIVE_ERR_UNDERFLOW.
