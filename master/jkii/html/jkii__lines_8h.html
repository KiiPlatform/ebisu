Detailed Description

Reading JSON Lines: one JSON value a line, fed in pieces of any size.

JSON Lines, or NDJSON, keeps one JSON value on each line, ended with '\n'. A device can append a record without rewriting what came before, and read them back one at a time, with a buffer the size of a record rather than of the whole file or response. A raw '\n' can't occur inside a JSON value, as a string escapes it, so the lines are split without parsing them.

char line_buff[256];
jkii_lines_t r;
jkii_lines_init(&r, line_buff, sizeof(line_buff));
while ((n = read(fd, chunk, sizeof(chunk))) > 0) {
const char* data = chunk;
size_t left = n;
while (left > 0) {
size_t used = 0;
const char* line = NULL;
size_t line_len = 0;
jkii_lines_err_t res = jkii_lines_feed(&r, data, left, &used, &line, &line_len);
data += used;
left -= used;
if (res == JKII_LINES_RECORD) {
// line_len bytes at line, terminated: give them to jkii_parse().
}
}
}
// And the last line, if the data didn't end with '\n'.

enum jkii_lines_err_t

What feeding a reader gives.

Enumerator
JKII_LINES_RECORD 

A record is whole: it is what the line points to.

JKII_LINES_NEED_MORE 

What was fed is consumed, and no record is whole yet.

JKII_LINES_TOO_LONG 

A record longer than the buffer has ended. It is skipped, up to the '\n' ending it, and the reader goes on with the next.

JKII_LINES_TRUNCATED 

From jkii_lines_finish(): the data ended in the middle of a record, with no '\n' after it, as after a power loss while appending. The line points to what there is of it, which may not parse.

JKII_LINES_END 

From jkii_lines_finish(): there is nothing left.

Feeds a reader what has come, as it comes: a whole file, or a piece of a response, of any size.

It consumes data until a record ends, or to the end. Feed it again with what is left, at data plus out_consumed. A record ends at '\n', with a '\r' before it taken off too. Empty lines, and lines of whitespace only, aren't records, and are skipped.

Parameters
[in,out]rThe reader.
[in]dataWhat has come.
[in]lenIts length.
[out]out_consumedHow much of data was consumed.
[out]out_lineWith JKII_LINES_RECORD, the record, in the buffer, terminated. It stays there until the reader is next fed or finished.
[out]out_line_lenIts length.
Returns
JKII_LINES_RECORD, JKII_LINES_NEED_MORE or JKII_LINES_TOO_LONG.
