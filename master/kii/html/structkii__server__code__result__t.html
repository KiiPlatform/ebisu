Detailed Description

A server code's response, as kii_get_server_code_result() reads it.

Its pointers are into the buffer set by kii_set_buff(), so it is good until the next request. A member that isn't there has jkii_member_t::value NULL and jkii_member_t::type JKII_FIELD_TYPE_ANY, which the jkii_member_ readers refuse as a type mismatch.
