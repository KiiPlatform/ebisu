◆ ebisu_file_logger_t

typedef struct ebisu_file_logger_t ebisu_file_logger_t

A logger to a file it keeps under a size, on POSIX and on Windows.

Each message is a line of its level and itself, as ebisu_stdio_logger_t writes it, after the system's time of day if ebisu_file_logger_set_timestamps() asks for it. A message less important than the logger's level is dropped. When a line would take the file past its size, the file is first renamed to its path with ".1" after it, which replaces the one there, and a new one is started: what the device keeps of its log is at most twice the size, and the last of it is in the file. A line longer than the size goes in a file of its own.

The line is formatted before the lock it is given is taken, and written, flushed and counted under it, as the file is renamed, so that it may be called from more than one task at once, which wait only for each other's writes. Nothing is lost but for the system failing to write: a file that can't be renamed is written past its size, and one that can't be opened is tried again with the next line.

Initialize with ebisu_file_logger_init(), and close with ebisu_file_logger_close().

◆ ebisu_stdio_logger_t

typedef struct ebisu_stdio_logger_t ebisu_stdio_logger_t

A logger to a stdio stream, such as stderr or a file.

Each message is a line of its level and itself, as in "error: failed to connect to example.com.". A message less important than the logger's level is dropped. The line is written with one call, which the C library of a POSIX system or of Windows doesn't let another task's writes to the stream come into, and flushed, so that it isn't lost if the program ends. So it may be called from more than one task at once.

Initialize with ebisu_stdio_logger_init().

◆ ebisu_syslog_logger_t

typedef struct ebisu_syslog_logger_t ebisu_syslog_logger_t

A logger to the system's syslog, on POSIX.

Each message goes to syslog() with the logger's facility and the severity of its level: LOG_ERR, LOG_WARNING, LOG_INFO or LOG_DEBUG. A message less important than the logger's level is dropped. openlog(), which names the program in each message and sets the facility by default, is the application's to call, if it wants to. syslog() may be called from more than one task at once, and so may the logger.

Initialize with ebisu_syslog_logger_init().

◆ ebisu_syslog_udp_logger_t

typedef struct ebisu_syslog_udp_logger_t ebisu_syslog_udp_logger_t

A logger to a syslog server, over UDP, on POSIX and on Windows.

Each message is a datagram of its own, formatted as RFC 5424 says and sent as RFC 5426 does: 

<PRI>1 TIMESTAMP HOSTNAME APP-NAME PROCID - - MSG

PRI is the logger's facility and the severity of the message's level, as ebisu_syslog_logger_t has them, TIMESTAMP the system's time of day, in UTC to the millisecond, HOSTNAME the name the logger is given, or the host's, as gethostname() gives it, APP-NAME the application's name, and PROCID the process's identifier. A message has no identifier and no structured data. The datagram is at most EBISU_LOGGER_LINE_MAX bytes. A message less important than the logger's level is dropped.

The server's address is looked up when the logger is initialized, and not for each message. Sending never waits: a datagram the socket can't take at once is dropped, as is one the network loses, as with any datagram. So the logger may be called from more than one task at once, and from one that mustn't wait, such as the MQTT task.

Initialize with ebisu_syslog_udp_logger_init(), and close with ebisu_syslog_udp_logger_close().

◆ ebisu_file_logger_set_timestamps()

void ebisu_file_logger_set_timestamps ( ebisu_file_logger_t * logger,
bool timestamps )

Sets whether each line starts with the time it is written.

The system's time of day, in UTC to the millisecond, as RFC 3339 has it, and a space, as in "2026-11-15T07:46:05.123Z error: failed to connect.", or "-" and a space if the system has no time. It is taken as the line is written, under the logger's lock, so that the times of a file's lines are in order, unless the system's clock is set back. The line, with it, is at most EBISU_LOGGER_LINE_MAX bytes still. Without it, as the logger starts, a line is as ebisu_stdio_logger_t's.

Only before the logger logs, from the task that initialized it, as for its other settings.

Parameters
[in,out]loggerThe logger.
[in]timestampsWhether each line starts with the time.

Initializes a logger to a syslog server over UDP, and makes base a logger of it.

It looks the server up, which may take as long as the system's resolver does, and opens a socket to it. If it can't, it returns false, and the logger drops every message until closed.

Parameters
[out]loggerThe logger.
[in]hostThe server's host name or address, IPv4 or IPv6.
[in]portIts port, 514 for syslog's.
[in]hostnameThe HOSTNAME the server is sent, which it tells hosts apart by, 1 to EBISU_SYSLOG_HOSTNAME_MAX printable ASCII characters without spaces, such as a device's serial number where every device has the same host name, or NULL for the host's name, as gethostname() gives it, or none if it gives none RFC 5424 can carry.
[in]app_nameThe application's name, 1 to EBISU_SYSLOG_APP_NAME_MAX printable ASCII characters without spaces, or NULL for none.
[in]facilityThe facility, as RFC 5424 numbers them, 0 to 23: 1 is user-level messages, 3 system daemons, and 16 to 23 local use 0 to 7.
[in]levelThe least important level sent: EBISU_LOG_WARNING sends errors and warnings.
[out]out_errorWhy it failed, or EBISU_LOGGER_INIT_ERROR_NONE if it didn't: EBISU_LOGGER_INIT_ERROR_ARGUMENT for an argument that isn't valid, EBISU_LOGGER_INIT_ERROR_LOOKUP for a host that can't be looked up, or EBISU_LOGGER_INIT_ERROR_OPEN if no socket opens to it. NULL for none.
Returns
true if the socket is open.
