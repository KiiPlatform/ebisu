typedef struct ebisu_win32_tcp_socket_t ebisu_win32_tcp_socket_t

A TCP connection over a blocking Winsock 2 socket, without TLS.

For a server that takes plain TCP, such as the MQTT broker's port without TLS, which kii_enable_insecure_mqtt() connects to. Nothing it sends or receives is encrypted or authenticated: anyone on the path can read it, and change it.

It connects as ebisu_schannel_socket_t does, with the same code, but for the TLS: see ebisu_win32_tcp_socket_set_connect_timeout(). A receive waits for data with select(), for no longer than its timeout, and only then reads it, so that a receive that times out leaves the socket as it was, as Winsock's own receive timeout wouldn't. It is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and a peer that closes the connection is the end of the stream. One serves one connection at a time, and is used again for the next once closed. Why an operation failed, its last_error says: a host that didn't resolve, with GetAddrInfoExW()'s error, an address that refused, with the Winsock error, a timeout, a peer that closed or reset the connection, or another failure, with the Winsock error. It also goes to the logger set by ebisu_win32_tcp_socket_set_logger(), if any.

Winsock has to have been started, with WSAStartup(), before the first connect, and the library links ws2_32.

Initialize with ebisu_win32_tcp_socket_init().

ebisu_dns_t * ebisu_win32_dns ( void )

The name servers on Windows, for platform's DNS probe.

The servers are those of the network adapters that are up, as GetAdaptersAddresses() gives them, in its order: IPv4 and IPv6, with an IPv6 one's scope, but one an earlier adapter has too, and the placeholders fec0:0:0:ffff::1 to ::3, which Windows lists for an adapter without an IPv6 server and which nothing answers on. Without any, there are none.

A server is asked over a UDP socket of Winsock 2 connected to it, so that its port unreachable is told, as Winsock reports it, with WSAECONNRESET. A scope's name is read by if_nametoindex() and said by if_indextoname(), and no server answering is WSATRY_AGAIN, getaddrinfo()'s EAI_AGAIN. Winsock has to have been started, with WSAStartup(), and the library links ws2_32 and iphlpapi. They have no state, so this serves everything.

◆ ebisu_win32_system()

ebisu_system_t * ebisu_win32_system ( void )

The system on Windows.

Each task runs on a thread of its own, made with _beginthreadex(), which nothing waits for. A delay is Sleep(). The monotonic clock is GetTickCount64(), which doesn't jump when the wall clock is set. The system has no state, so this one serves everything.

Returns
The system.

void ebisu_win32_tcp_socket_set_connect_timeout ( ebisu_win32_tcp_socket_t * sock,
unsigned int seconds )

Sets how long connecting may take.

The host is looked up with GetAddrInfoExW(), and its addresses tried in the order it gives them, IPv6 and IPv4, until one connects. The timeout bounds the lookup, which is cancelled when it runs out, and each attempt to connect to an address.

Parameters
[out]sockThe socket.
[in]seconds0 for no bound: the lookup takes as long as the system's resolver does, and an attempt as long as the system's TCP does.

void ebisu_win32_tcp_socket_set_logger ( ebisu_win32_tcp_socket_t * sock,
ebisu_logger_t * logger )

Sets where the socket's diagnostics go.

Why an operation failed, at EBISU_LOG_ERROR: a host that didn't resolve or connect, a send or a receive that failed, with the Winsock error and the system's text for it. A receive that times out isn't one.

Built with EBISU_NO_LOG, as -DEBISU_LOG=OFF builds it, the socket logs nothing.

Parameters
[out]sockThe socket.
[in]loggerThe logger, which has to outlive the socket, or NULL, as the socket starts, for the diagnostics to go nowhere.
