ebisu_system_t * ebisu_win32_system ( void )

The system on Windows.

Each task runs on a thread of its own, made with _beginthreadex(), which nothing waits for. A delay is Sleep(). The monotonic clock is GetTickCount64(), which doesn't jump when the wall clock is set. The system has no state, so this one serves everything.

Returns
The system.
