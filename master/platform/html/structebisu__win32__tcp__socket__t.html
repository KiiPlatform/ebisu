Detailed Description

A TCP connection over a blocking Winsock 2 socket, without TLS.

For a server that takes plain TCP, such as the MQTT broker's port without TLS, which kii_enable_insecure_mqtt() connects to. Nothing it sends or receives is encrypted or authenticated: anyone on the path can read it, and change it.

It connects as ebisu_schannel_socket_t does, with the same code, but for the TLS: see ebisu_win32_tcp_socket_set_connect_timeout(). A receive waits for data with select(), for no longer than its timeout, and only then reads it, so that a receive that times out leaves the socket as it was, as Winsock's own receive timeout wouldn't. It is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and a peer that closes the connection is the end of the stream. One serves one connection at a time, and is used again for the next once closed. Why an operation failed, its last_error says: a host that didn't resolve, with GetAddrInfoExW()'s error, an address that refused, with the Winsock error, a timeout, a peer that closed or reset the connection, or another failure, with the Winsock error. It also goes to the logger set by ebisu_win32_tcp_socket_set_logger(), if any.

Winsock has to have been started, with WSAStartup(), before the first connect, and the library links ws2_32.

Initialize with ebisu_win32_tcp_socket_init().
