Detailed Description

A TCP connection over a blocking BSD socket, without TLS.

For a server that takes plain TCP, such as the MQTT broker's port without TLS, which kii_enable_insecure_mqtt() connects to. Nothing it sends or receives is encrypted or authenticated: anyone on the path can read it, and change it.

It connects as ebisu_openssl_socket_t does, with the same code, but for the TLS: see ebisu_posix_tcp_socket_set_connect_timeout(). A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and a peer that closes the connection is the end of the stream. A send to a peer that has gone fails, and never raises SIGPIPE. One serves one connection at a time, and is used again for the next once closed. Why an operation failed, its last_error says: a host that didn't resolve, with getaddrinfo()'s error, an address that refused, with errno, a timeout, a peer that closed or reset the connection, or another failure, with errno. It also goes to the logger set by ebisu_posix_tcp_socket_set_logger(), if any.

Initialize with ebisu_posix_tcp_socket_init().
