Detailed Description

A TLS connection over a Winsock socket, with Schannel through SSPI.

Schannel negotiates the protocol versions the system enables, TLS 1.2 at most, and the socket checks the server's certificate itself, with crypt32: a chain to a root in the Windows root store, valid for server authentication, issued for the host, and in date at the time of the clock set by ebisu_schannel_socket_set_clock(), or the system's without one. Revocation isn't checked. A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and leaves the connection as it was. One serves one connection at a time, and is used again for the next once closed. Why an operation failed is printed to stdout. Winsock has to have been started, with WSAStartup(), before the first connection.
