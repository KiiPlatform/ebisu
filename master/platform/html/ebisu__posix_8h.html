ebisu_system_t * ebisu_posix_system ( void  )

The system on POSIX.

Each task is a detached thread, which goes by itself when it ends. A delay is nanosleep(), resumed through signals until the whole time has passed. The monotonic clock is CLOCK_MONOTONIC. The system has no state, so this one serves everything.

The system.
