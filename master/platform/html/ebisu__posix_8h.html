typedef struct ebisu_posix_tcp_socket_t ebisu_posix_tcp_socket_t

A TCP connection over a blocking BSD socket, without TLS.

For a server that takes plain TCP, such as the MQTT broker's port without TLS, which kii_enable_insecure_mqtt() connects to. Nothing it sends or receives is encrypted or authenticated: anyone on the path can read it, and change it.

It connects as ebisu_openssl_socket_t does, with the same code, but for the TLS: see ebisu_posix_tcp_socket_set_connect_timeout(). A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and a peer that closes the connection is the end of the stream. A send to a peer that has gone fails, and never raises SIGPIPE. One serves one connection at a time, and is used again for the next once closed. Why an operation failed, its last_error says: a host that didn't resolve, with getaddrinfo()'s error, an address that refused, with errno, a timeout, a peer that closed or reset the connection, or another failure, with errno. It also goes to the logger set by ebisu_posix_tcp_socket_set_logger(), if any.

Initialize with ebisu_posix_tcp_socket_init().

ebisu_dns_t * ebisu_posix_dns ( void )

The name servers on POSIX, for platform's DNS probe.

The servers are those of the nameserver lines of /etc/resolv.conf whose address is one, in order, on port 53, as the C libraries take them: an IPv6 address's scope is read as ebisu_dns_parse_address() reads it, an interface's name by if_nametoindex(), and a line with another scope is taken without it where the port is built with glibc, and skipped where it isn't, as glibc and musl do. So are the lines read: with glibc, split at spaces and tabs, and whole, however long, and otherwise split at what isspace() takes, a line longer than 254 bytes skipped. An address ends at a blank: a '#' or a ';' right after it makes it one no longer. Without a server, or without the file, it is 127.0.0.1, as for the C libraries.

A server is asked over a UDP socket connected to it, so that its port unreachable is told. A scope is said as its interface's name, by if_indextoname(), and no server answering is EAI_AGAIN, as for getaddrinfo(). They have no state, so this serves everything.

Returns
The name servers.

◆ ebisu_posix_system()

ebisu_system_t * ebisu_posix_system ( void )

The system on POSIX.

Each task is a detached thread, which goes by itself when it ends. A delay is nanosleep(), resumed through signals until the whole time has passed. The monotonic clock is CLOCK_MONOTONIC. Its locks, from ebisu_system_lock_create(), are ebisu_posix_lock_t's from the heap. The system has no state, so this one serves everything.

Returns
The system.

◆ ebisu_posix_tcp_socket_set_connect_timeout()

void ebisu_posix_tcp_socket_set_connect_timeout ( ebisu_posix_tcp_socket_t * sock,
unsigned int seconds )

Sets how long connecting may take.

The host is looked up with getaddrinfo(), and its addresses tried in the order it gives them, IPv6 and IPv4, until one connects. The timeout bounds the lookup, and each attempt to connect to an address.

getaddrinfo() can't be given a timeout: a lookup the timeout cuts short goes on, on a thread of its own, for as long as the system's resolver takes. A connect to the same host and port meanwhile, of any of these sockets, waits for that lookup, within its own timeout, rather than start another: lookups that don't end leave a thread for each host and port, however often connects time out on them.

Parameters
[out]sockThe socket.
[in]seconds0 for no bound: the lookup takes as long as the system's resolver does, and an attempt as long as the system's TCP does.

void ebisu_posix_tcp_socket_set_keepalive ( ebisu_posix_tcp_socket_t * sock,
unsigned int idle_s,
unsigned int interval_s,
unsigned int count )

Sets whether TCP checks an idle connection is still there.

With keepalive, TCP probes a connection that has been idle for idle_s seconds, and gives the connection up when count probes, interval_s seconds apart, go unanswered: a send or a receive on it then fails, rather than the next request finding out. So a peer that lost power, or a NAT that dropped the connection's entry, is noticed within about idle_s + interval_s * count seconds of the connection going idle.

It applies from the next connect: SO_KEEPALIVE, with TCP_KEEPIDLE (TCP_KEEPALIVE on macOS), TCP_KEEPINTVL and TCP_KEEPCNT where the system has them. One the system hasn't, or a value it refuses, as Linux refuses an idle time or an interval over 32767 seconds and a count over 127, is said at EBISU_LOG_WARNING to the logger, and the connection made without it.

Parameters
[out]sockThe socket.
[in]idle_sSeconds idle before the first probe, or 0 for no keepalive, as the socket starts.
[in]interval_sSeconds between probes, or 0 for the system's.
[in]countProbes unanswered before the connection is given up, or 0 for the system's.

Sets where the socket's diagnostics go.

Why an operation failed, at EBISU_LOG_ERROR: a host that didn't resolve or connect, a send or a receive that failed. A receive that times out isn't one.

Built with EBISU_NO_LOG, as -DEBISU_LOG=OFF builds it, the socket logs nothing.

bool nodelay )

Sets whether what is sent goes at once, with TCP_NODELAY.

Without it, as the socket starts, Nagle's algorithm holds a small segment back while an earlier one is unacknowledged: a request sent in two pieces can wait for the first's ACK, which a peer may delay. It applies from the next connect. A system that refuses it is said at EBISU_LOG_WARNING.

Parameters
[out]sockThe socket.
[in]nodelaytrue to send at once.
