enum ebisu_sock_code_t

Indicates socket callback result.

Enumerator
EBISU_SOCK_OK 

Retrun this code when operation succeed.

EBISU_SOCK_FAIL 

Return this code when operation failed.

EBISU_SOCK_AGAIN 

Return this code when operation is in progress.

This code is used when the underlying socket is non-bloking mode. The callback is called again with the same argument until the callbacks returns EBISU_SOCK_OK or EBISU_SOCK_FAIL.
