typedef struct ebisu_openssl_socket_t ebisu_openssl_socket_t

A TLS connection over a blocking BSD socket, with OpenSSL.

It verifies the server's certificate chain against the system's CA certificates, and the host name, at the time of the clock set by ebisu_openssl_socket_set_clock(), or the system's without one, against the CA certificates of the configuration set by ebisu_openssl_socket_set_tls(), or the system's without one. A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection. One serves one connection at a time, and is used again for the next once closed. A connection offers the server the session of the last one to the same host and port to resume, from those its configuration keeps, which saves most of the handshake if the server takes it. Why an operation failed, its last_error says: a host that didn't resolve, with getaddrinfo()'s error, an address that refused, with errno, a certificate rejected, with X509_V_ERR_*, another TLS failure, with OpenSSL's error code, a timeout, or a peer that closed. It also goes to the logger set by ebisu_openssl_socket_set_logger(), or to stderr without one. OpenSSL 1.0.2 and later, initialized and made thread-safe on first use.

◆ ebisu_openssl_tls_t

typedef struct ebisu_openssl_tls_t ebisu_openssl_tls_t

The TLS configuration connections share.

One SSL_CTX, with the CA certificates servers' certificates have to chain to, set up once rather than for each connection. Sockets of any number of tasks may share one. It keeps the TLS sessions of the last connections to a few hosts, for the next connection to each to resume, until it is freed. Sockets without a configuration share the one with the system's CA certificates, which is never freed.

Sets how long connecting may take.

The host is looked up with getaddrinfo(), and its addresses tried in the order it gives them, IPv6 and IPv4, until one connects. The timeout bounds the lookup, and each attempt to connect to an address, but not the TLS handshake, which the receive and send timeouts bound.

Parameters
[out]sockThe socket.
[in]seconds0 for no bound: the lookup takes as long as the system's resolver does, and an attempt as long as the system's TCP does.

Sets up a TLS configuration.

Its connections are TLS 1.2 or later, and in TLS 1.2 take only suites with forward secrecy and authenticated encryption: ECDHE or DHE, with AES-GCM or ChaCha20-Poly1305. So are those of the configuration sockets without one share.

For a device without the system's CA certificates, or with them where OpenSSL doesn't look, give the CA certificates the servers' chain to. Without either, the system's are used, from where OpenSSL was built to find them, as when no configuration is set.

Parameters
[out]tlsThe configuration.
[in]ca_fileFile of PEM CA certificates, or NULL.
[in]ca_pathDirectory of CA certificates named by their hash, as openssl rehash or c_rehash names them, or NULL.
Returns
true, or false if the certificates couldn't be loaded or OpenSSL failed, which OpenSSL's error queue on the calling thread says more of, as ERR_get_error() reads it.
