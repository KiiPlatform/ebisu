typedef struct ebisu_dns_probe_socket_t ebisu_dns_probe_socket_t

A socket that asks whether the name servers answer before another connects.

Its connect probes as ebisu_dns_probe() does, then has the other socket connect, unless no server answered: then it fails, without the other socket connecting, and its last_error is EBISU_SOCK_ERROR_DNS, with EAI_AGAIN, getaddrinfo()'s error for a resolver that didn't answer. A connect the other socket goes on with, after EBISU_SOCK_AGAIN, isn't probed again. Close closes the other socket, or does nothing if it didn't connect.

Everything else is the other socket's: send, recv and last_error, and recv_timed_out and recv_wait if it has them, and only then.

Why a connect failed goes to the logger set by ebisu_dns_probe_socket_set_logger(), if any: at EBISU_LOG_ERROR, that no server answered, and at EBISU_LOG_INFO, once, that one answers again, after how many connects failed.

Initialize with ebisu_dns_probe_socket_init().

What a probe found.

Enumerator
EBISU_DNS_PROBE_ANSWERED 

A name server answered, so a lookup now gets an answer, though not necessarily an address.

EBISU_DNS_PROBE_NOT_NEEDED 

The host needs no name server: an address, IPv4 in any form inet_aton() takes or IPv6, localhost or a name under it, which RFC 6761 keeps out of DNS, or a name no query can carry, whose lookup fails at once.

EBISU_DNS_PROBE_SILENT 

No name server answered in time, or none could be asked: a lookup now may wait for as long as the C library keeps asking again.

ebisu_dns_probe_result_t ebisu_dns_probe ( const char * host,
uint32_t timeout_ms,
char * detail,
size_t detail_size )

Asks the system's name servers whether they answer.

getaddrinfo() can't be given a timeout: when the name servers don't answer, a lookup waits for as long as the C library keeps asking them again, which can be minutes, and so does the task that looked up. This asks first, in a time it bounds, so that the task can give up instead.

It sends one recursive query, for the host's IPv4 addresses, over UDP, to each of the servers the system's lookups ask in turn, until one answers. Each is given timeout_ms. Any answer counts, that the name doesn't exist too: nothing is looked up, only whether a server answers. A datagram that isn't the answer to the query is skipped.

The servers are those of the first 3 nameserver lines of /etc/resolv.conf whose address is one, in order, on port 53, as the C libraries take them. A server a line repeats takes a place, but is asked once. An IPv6 address's scope is read as ebisu_dns_server_t's is. A line with another scope is asked without it where the probe is built with glibc, and skipped where it isn't, as glibc and musl do. Without a server, or without the file, it is 127.0.0.1, as for the C libraries.

A name a lookup gets from elsewhere, such as /etc/hosts, still needs the servers to answer: the probe tells only whether they do.

Parameters
[in]hostThe host to be looked up.
[in]timeout_msHow long each server has to answer, in milliseconds.
[out]detailFor a log, what happened: which server answered, or what the last one asked did, as in "127.0.0.1:53 didn't answer in time", or NULL. It is cut short to fit, and is always terminated.
[in]detail_sizeIts size, EBISU_DNS_PROBE_DETAIL_SIZE for room for any.
Returns
What it found.
