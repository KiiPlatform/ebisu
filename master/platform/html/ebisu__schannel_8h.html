typedef struct ebisu_schannel_socket_t ebisu_schannel_socket_t

A TLS connection over a Winsock socket, with Schannel through SSPI.

Schannel negotiates the protocol versions the system enables, TLS 1.2 at most, and the socket checks the server's certificate itself, with crypt32: a chain to a root in the Windows root store, valid for server authentication, issued for the host, and in date at the time of the clock set by ebisu_schannel_socket_set_clock(), or the system's without one. Revocation isn't checked. A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection, and leaves the connection as it was. One serves one connection at a time, and is used again for the next once closed. Why an operation failed, its last_error says: a host that didn't resolve, with getaddrinfo()'s error, an address that refused, with the Winsock error, a certificate refused, with the CERT_E_* or TRUST_E_* code, a TLS failure, with the SSPI status, a timeout, or a peer that closed or reset the connection, with the Winsock error if there is one. It also goes to the logger set by ebisu_schannel_socket_set_logger(), or to stderr without one. Winsock has to have been started, with WSAStartup(), before the first connection.

Sets where the socket's diagnostics go.

Why an operation failed, at EBISU_LOG_ERROR: a host that didn't resolve or connect, a certificate refused and why, Schannel's or Winsock's error, with the system's text for it. A receive that times out isn't one.

Parameters
[out]sockThe socket.
[in]loggerThe logger, which has to outlive the socket, or NULL for stderr.
