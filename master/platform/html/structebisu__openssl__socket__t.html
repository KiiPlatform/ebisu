Detailed Description

A TLS connection over a blocking BSD socket, with OpenSSL.

It verifies the server's certificate chain against the system's CA certificates, and the host name, at the time of the clock set by ebisu_openssl_socket_set_clock(), or the system's without one, against the CA certificates of the configuration set by ebisu_openssl_socket_set_tls(), or the system's without one. A receive that times out is EBISU_SOCK_FAIL, which recv_timed_out tells from a lost connection. One serves one connection at a time, and is used again for the next once closed. A connection offers the server the session of the last one to the same host and port to resume, from those its configuration keeps, which saves most of the handshake if the server takes it. Why an operation failed, its last_error says: a host that didn't resolve, with getaddrinfo()'s error, an address that refused, with errno, a certificate rejected, with X509_V_ERR_*, another TLS failure, with OpenSSL's error code, a timeout, or a peer that closed. It also goes to the logger set by ebisu_openssl_socket_set_logger(), if any. OpenSSL 1.0.2 and later, initialized and made thread-safe on first use.
